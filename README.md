# martinigoyanes.github.io

Personal site for Martin Igoyanes — AI Research Engineer. Hosted on GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:4321 to preview.

## Build

```bash
npm run build
```

Output is written to `dist/`.

## Deploy

The site is deployed automatically via GitHub Actions on every push to `main`
(see `.github/workflows/deploy.yml`). After the first push, enable GitHub Pages:

1. Repo → **Settings** → **Pages**
2. Set **Source** to **GitHub Actions**

The site will be live at https://martinigoyanes.github.io.
